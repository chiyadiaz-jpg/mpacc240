# MPAcc 240 作战室

蓝色玻璃风格的个人 MPAcc 学习管理网页，支持每日任务、专注计时、备考地图、模考统计与 JSON 备份，重点加强数学与综合推理。

## Vercel 部署

导入本仓库即可部署，无需环境变量。`vercel.json` 会解压完整源码，安装依赖，运行 13 项算法测试并构建网页，仅发布 `mpacc240/dist`。部署状态与网址在 Vercel 项目中查看。

## 源码与更新

完整 React + TypeScript + Vite 源码、测试、使用说明位于根目录的 `mpacc240-source.zip` 内。解压后进入 `mpacc240` 文件夹，即可运行 `npm ci`、`npm test`、`npm run dev` 或 `npm run build`。

更新时，将修改后的源码重新打包为相同名称的 ZIP，保留其中 `mpacc240/` 这一层目录，并提交到 `main`。Vercel 会自动构建更新。不要把 `node_modules`、学习备份或 `.env` 放入压缩包。

本项目以 Vercel 为正式部署平台。源码包中附带的 GitHub Pages 工作流仅供选用，不会在本仓库自动执行。

## 数据保存

初始配置包含经项目所有者同意公开的首模 205 分、目标 240 分及各科初始进度。每个人之后填写的学习记录只保存在自己的浏览器中，不上传到 GitHub 或 Vercel。

从本地网页迁移时，请先在原地址的“设置与备份”导出 JSON，再在正式网址导入。不同设备和浏览器不会自动同步，请定期导出备份。
